# 回声 · Windows 本地音色工作室

以参考音频和新文字生成语音，使用 IndexTTS-2.5。每次提交依次生成三份独立结果，完成一份即显示试听与下载；后台显示音频识别文字，内容由使用者自行校对，不自动比对或重试。

**当前状态：IndexTTS 已在本机生成过语音。启动预加载、常驻模型和单分支生成已接入；同一约 2.03 秒样本的两次暖机请求总耗时为 2.55 秒、1.62 秒（本机单次测试，不代表所有文本）。波形裁剪、CPU 环境降噪、音乐分离和组合处理已实现并通过本机实测。**

## 离线安装与迁移

Windows 离线发行版随包提供两套独立 Python、IndexTTS-2.5 主模型与辅助权重、Whisper small、本地音频分离模型、FFmpeg 和运行库安装器。无需在目标电脑下载 Python、pip 依赖或模型。

将私有 Release 的安装入口、清单和全部 ZIP 分卷复制到同一文件夹，双击 **Install.exe**。安装器自动校验、解压并创建 **音色工作室（离线版）** 桌面入口；之后一键启动。已有录音、生成结果、账号凭据和下载缓存不进入分发包。

目标为 Windows 10/11 64 位，支持 BF16 的 NVIDIA 显卡（建议 RTX 30/40/50 系列、8 GB 或以上显存）以及可运行所带 CUDA 12.8 的显示驱动。驱动由系统提供；不需要安装 CUDA Toolkit。全部现有创作功能保留。详细说明见 [离线使用说明](distribution/README-OFFLINE.md)。

## 本地源码开发安装

日常使用：桌面双击 **音色工作室** 即可，服务已运行时直接打开页面，未运行时后台启动。无需打开项目文件夹或保留命令窗口；关闭软件请点页面右上角 **退出软件**。项目文件夹请保留在当前路径，桌面快捷方式依赖其中的程序与模型。

1. 在本项目文件夹中，双击 **安装IndexTTS.cmd**。无需管理员权限。
2. 保持窗口打开，等待最后显示“安装完成”。首次安装可能下载数 GB 至十余 GB 文件，取决于依赖和辅助模型。失败日志在 `logs/install-index.log`。
3. 双击 **启动音色工作室.cmd**。浏览器打开 `http://127.0.0.1:7865`，生成时保留命令窗口。
4. 上传录音（最大 **64 MB / 10 分钟**），波形会自动显示。拖动选区后直接点 **裁剪选区** 一键应用；可用“精确选区”输入起止时间。选取 **1–30 秒**作为参考，无需填写参考原文。
5. 填写新文字并点击“连续生成 3 次”。三次使用不同随机种子，按第 1、2、3 次顺序执行，复用同一个常驻模型；不同种子不保证每次听感都有明显差别。
6. 每份音频完成后立即显示播放器和下载链接。识别文字在后台用本地 CPU 模型依次生成，不等待识别就能试听和下载；识别失败也不影响音频。软件不比较文字、不打分、不筛选、不自动重试，由你自行试听、校对和选用。取消时保留已完成音频。

先前的自动安装在访问 PyPI 时发生 TLS 中断，未下载模型。请先尝试在你的普通 Windows 会话中运行上述安装器；遇到失败，把末尾错误或日志内容提供给我，以便继续针对性修复。

## 每条启动命令做什么

双击安装脚本相当于执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install.ps1 -Engine index
```

- 原因：为 IndexTTS-2.5 建立独立环境并下载官方权重。
- `-NoProfile` 不加载个人 PowerShell 启动配置；`-ExecutionPolicy Bypass` 仅对本次 PowerShell 进程允许执行项目脚本，不修改系统执行策略；`-File` 指定脚本；`-Engine index` 安装 IndexTTS-2.5。`app` 仅安装界面环境与参考原文识别依赖。
- 后果：向项目内下载 Python、依赖、源码、模型和缓存，并写入安装日志。无需改注册表、系统 PATH 或系统 Python。模型依赖的构建过程由上游安装程序执行。

双击启动脚本相当于执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\launch.ps1
```

- 原因：启动本机交互界面。
- 参数与安装脚本相同；这里 `-File` 指向启动脚本。
- 后果：在 `127.0.0.1:7865` 启动服务并打开默认浏览器，只监听本机；关闭命令窗口会停止服务。端口已被占用时需要先关闭原窗口。

## 如何理解功能边界

- 生成界面采用普通进度条和一行小字，例如“生成中 42% · 已用 00:18 · 剩余约 00:26”。提交后立即查询状态，之后每秒串行更新，完成后自动显示音频；状态请求超过 8 秒会自动中断并重新查询，切回标签页时立即同步。首次加载使用不定进度动画，后续复用时跳过加载预算。预计时间根据 `data/performance.json` 中的本机耗时逐步调整，不包含自动识别复核；估计失准时显示“剩余估算中”。失败、取消和完成后停止计时。
- 支持一秒参考音频。不足三秒只显示提示，不阻止操作；录音越短，可供提取的说话人和情感信息越有限，实际效果需要试听验证。上传最长 10 分钟，合成使用的选区限制为 1–30 秒。
- 这是基于参考声音的重新合成，**无法保证任意新文字都逐字复刻原录音的音高曲线、停顿和情感**；也不保证与原录音等长。
- IndexTTS 将同一录音作为音色参考和情感参考，不需要填写参考原文。
- 长文按长度拆分，短句在 72 字限制内合并，减少重复调用；每次独立结果的单片直接复制，多片拼接保存。三份结果分别合成，不是复制同一音频；每份内部的片段只生成一次，不做识别比对或自动重试。某次运行失败会显示错误，其余次数继续执行。
- IndexTTS 使用 `num_beams=1`，减少原先三个候选分支的计算；保留 BF16、参考音色和情感参数，朗读速度不变。单分支可能改变读音、表现力或稳定性，需要试听评估。
- 页面采用暖白、陶土色的简约工作区，侧栏默认收起、展开时浮于工作区上方。参考原文输入与识别按钮已移除。上传、文字输入、语言选择、生成和导出集中在单屏工作区；分段试听和使用说明通过弹窗打开，长内容只在输入框、弹窗内滚动。
- 上传后展示真实波形，可拖动边界、输入起止时间、预听选区、应用裁剪、恢复原始上传。生成会自动应用当前选区；裁剪与分离都写入新文件，不覆盖原始上传。音频保留为 44.1 kHz 双声道，供后续编辑与分离，合成模型按自身接口读取参考音频。
- 不做自动内容检查，不保证文字与音频完全一致。建议将数字、日期、单位写成实际读法，并自行试听。
- 当前为本地浏览器界面和 Windows 双击启动器，尚未打包为独立 EXE。

## 安装布局与显存

RTX 5060 8GB：保持一个 IndexTTS 进程驻留，连续任务复用模型；使用同一已上传参考音频时也复用声音特征。取消任务、模型报错或点击“退出软件”会关闭引擎进程并释放显存。关闭网页标签页会保留后台及显存，便于继续生成。IndexTTS 使用 BF16；关闭额外 CUDA 编译、DeepSpeed、TensorRT 和 vLLM。

## 可选音频处理

首次使用可双击 **安装音频处理.cmd**。它仅在项目界面 `.venv` 中安装 `sherpa-onnx==2.0.1`，下载官方 GTCRN（约 0.5 MB）和 UVR（约 30 MB）到 `models/audio/`，验证大小、UVR 官方 SHA-256，并测试本地加载；不修改 IndexTTS 环境。当前工作区已完成安装。

点击参考声音标题旁的独立入口 **人声分离**，选择环境降噪、背景音乐分离，或先去音乐再清理噪音。分离弹窗与裁剪界面分开，只处理当前 1–30 秒选区，使用 CPU 两个线程，不额外占用模型显存，也不会在每次生成时自动执行。结果提供人声与背景两条音轨，分别试听、下载，并可将人声设为新参考；处理时可取消。

环境降噪输出会恢复到输入采样率并对齐长度。背景音轨是原片段减去提取人声得到的移除成分，可能残留人声；强混响、重叠说话、极低信噪比不保证完全分离。GTCRN 在 16 kHz 下增强语音，可能改变高频细节，请试听判断是否适合作为音色参考。

本机一份 2 秒测试素材的 CPU 处理耗时：环境降噪约 0.21 秒，音乐分离约 1.14 秒，组合处理约 1.37 秒；实际耗时随长度、机器负载和素材变化。测试记录在 `.cache/audio-smoke/`，生成测速记录在 `.cache/tts-speed-check.json`。

IndexTTS 固定源码标签 `v2.5.0`，安装记录在 `engines/index/local-install.json`。辅助模型仍可能在首次合成时联网下载；完整首次合成成功后才能验证断网使用。

```text
.runtime/           项目专用 Python 3.11
.tools/             安装工具
.venv/              界面、音频转换和 CPU 语音识别依赖
engines/index/      IndexTTS 源码、独立环境和权重
models/asr/         语音识别权重
models/audio/       CPU 降噪和音乐分离权重
.cache/             下载缓存
data/uploads/       上传后转换的参考 WAV
data/jobs/          任务片段、完整音频、任务记录和运行日志
data/processing/    音频分离任务状态和运行日志
logs/               安装日志
```

音频与文字不上传第三方合成服务。首次安装和辅助权重下载需要连接官方分发服务。当前页面显示本次服务启动后的任务，历史文件仍保存在 `data/jobs/`。

## 故障定位

- 已下载识别模型却提示无法找到缓存快照、`local_files_only=False`：不要直接改成联网模式。新版会按 `models/asr/small/` 的明确目录加载，并在界面检查后台版本。如果旧后台仍在占用端口，双击 **重启音色工作室.cmd** 后按 `Ctrl+F5`。该入口只结束命令行参数明确指向本项目 `app.py` 的 Python 服务，再启动新版；不删除模型或音频。它会中断该服务正在进行的任务，适合当前任务已失败后使用。若系统不允许查询进程，脚本会停止并提示手动关闭旧终端，不会结束其他 Python 进程。
- wetext/kaldifst 报错无法打开 `traditional_to_simple.fst`，但该文件存在：Windows 原生 FST 读取器可能无法处理中文绝对路径。软件现已在工作进程导入 wetext 时将资源路径转换为相对 ASCII 路径，不需要搬动项目或重下模型。可通过重启软件应用修复。
- 提示 `FileNotFoundError` 且缺少 `bigvgan_generator.pt`：只运行 **补下载BigVGAN.cmd**，不会检查或重下主模型。等待显示“BigVGAN 补下载完成并校验通过”，关闭旧服务再启动。软件现在会在任务开始前检查辅助模型，缺失时直接显示所需修复入口。
- 下载完成后出现 PowerShell 的“索引超出了数组界限 / NativeCommandFailed”：新版补下载 `.cmd` 已直接调用 Python，并由 Python 写入 `logs/download-models.log`，避免经过该 PowerShell 调用层。若模型文件已校验通过，无需因此重新下载。
- BigVGAN 下载不动：关闭旧补下载窗口后，再运行更新后的 `补下载IndexTTS模型.cmd`。BigVGAN 已改用 ModelScope 的 `nv-community/bigvgan_v2_22khz_80band_256x` 托管副本；权重 SHA-256 与 NVIDIA 官方发布值一致。该文件显示下载进度，连接超时 5 秒、读取无数据超时 20 秒，最多连接两次，未完成的 `.part` 文件保留以便续传。若服务器不支持续传，只重取当前未完成文件。主模型会先校验，已有正确文件跳过 SDK 下载；请勿同时启动多个下载窗口。
- 日志出现无法连接 `huggingface.co`、`WinError 10061` 或 `LocalEntryNotFoundError`：依赖环境若已安装，双击 **补下载IndexTTS模型.cmd**，无需重新安装全部依赖。该脚本使用现有 IndexTTS 环境，优先从 ModelScope 下载官方 IndexTTS 主模型与辅助文件；少数辅助模型可能按上游逻辑回退到 `hf-mirror.com`。识别模型先尝试 ModelScope 的 `Systran/faster-whisper-small`，不可用时尝试 `pengzhendong/faster-whisper-small` 托管副本，下载到 `models/asr/small/`。下载后检查必要文件、下载源提供的大小与 SHA-256（若提供），并测试识别模型能从本地加载。完整日志在 `logs/download-models.log`。此检查不等于已完成真实语音合成验证。
- 页面显示为纯文字或布局散乱：使用项目中的 `启动音色工作室.cmd` 启动，再访问 `http://127.0.0.1:7865`；更新代码后先关闭旧服务再启动，并在浏览器按 `Ctrl+F5` 强制刷新。直接打开 HTML 只适合预览外观，无法生成音频。
- 模型未安装完成：查看 `logs/install-index.log`。
- 生成失败：界面点击“运行日志”查看三次运行的合并日志；各次原始日志保存在 `data/jobs/各次结果编号/engine.log`，编号可在任务记录中查看。
- 约两秒内容首次等待二十余秒：检查右上方模型状态和任务记录中的 `timings`、`model_reused`。启动准备与实际合成分别计时；保持后台运行可复用模型与参考特征，退出软件后下次仍需重新加载。
- 显存不足：先关闭占用 GPU 的程序，用短句重试；仍失败时保留日志，继续调整模型装载策略。
- 参考原文识别提示本地模型缺失：运行 **补下载IndexTTS模型.cmd** 补齐识别权重；语音生成不依赖识别模型。
- 依赖下载中断：安装器可以重跑，复用已完成的下载。不要直接覆盖系统 Python。

完整 Windows 离线发行版，包含 IndexTTS-2.5、两套独立 Python、主模型与辅助权重、Whisper small、音频分离模型及 FFmpeg。

将本 Release 的 **全部附件**保存到同一文件夹，双击 **Install.exe**。可先在有网络的电脑获取，再用移动硬盘拷贝到离线电脑；目标安装及运行不需要下载模型或依赖。`payload-inventory.json` 和 `verification.json` 是文件清单与验证记录。

保留全部现有功能：

- 一次提交顺序生成三份独立音频，完成一份即可试听、下载。
- 本地识别文字后台显示，仅供人工校对，不自动比对、筛选或重试。
- 波形、裁剪、精确选区、预听、恢复原始上传。
- 环境降噪、背景音乐分离及组合处理，人声和环境/背景音分别导出。
- 左右工作区、6:4 上传/波形比例、自动刷新、常驻模型和桌面一键启动。

要求 Windows 10/11 64 位、支持 BF16 的 NVIDIA 显卡，建议 RTX 30/40/50 系列与 8 GB 或更多显存。需要目标系统具备支持 CUDA 12.8 的 NVIDIA 显示驱动；不需要另装 CUDA Toolkit。

安装器自动校验分卷、恢复大文件、检查运行环境并创建桌面快捷方式。微软运行库安装器随包提供，确有需要时 Windows 可能请求系统安装授权。首次启动仍需加载模型，退出软件或关机后下次会重新加载。

不包含开发电脑上的个人音频、生成记录、日志、GitHub 凭据和下载缓存。第三方程序和模型保留原始许可；详见附件中的 `THIRD_PARTY_NOTICES.md` 和 IndexTTS 完整许可。

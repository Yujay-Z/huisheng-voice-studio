# 回声 · 音色工作室离线版

## 在另一台电脑安装

1. 将 `Install.exe`、`Install-Offline.ps1`、`offline-manifest.json` 和全部 `HuishengVoiceStudio-*.zip` 分卷放在同一文件夹。文件可通过移动硬盘或 U 盘携带；不需要目标电脑联网。
2. 双击 **Install.exe**，选择安装目录，接受随附第三方许可，点击安装。安装器自动校验所有分卷、恢复大权重文件、检查本地环境并创建 **音色工作室（离线版）** 桌面快捷方式。
3. 双击桌面图标启动。也可以双击安装目录中的 **音色工作室.exe**。无需安装 Python、CUDA Toolkit 或通过 pip 下载任何内容。

安装器已带微软运行库原始安装程序；确有需要时，Windows 会请求系统安装授权。NVIDIA 显示驱动由目标系统提供，需要支持所带 PyTorch 2.8 / CUDA 12.8。建议支持 BF16 的 RTX 30/40/50 系列、8 GB 或更多显存，Windows 10/11 64 位。不同显卡和驱动上的速度可能不同。

安装过程中显示校验、解压和环境检查进度。若意外中断，使用同一套分卷和同一安装目录再次安装可从完成的分卷继续。不覆盖无本安装记录的现有目录，不会替换你的其他 Python 环境。

## 包内功能

- IndexTTS-2.5 参考音色与情感克隆，1–30 秒参考选区。
- 一次提交依次生成三份独立结果，使用不同随机种子；完成一份即显示试听和下载。
- 本地识别文字在后台补齐，供人工校对；不自动比较、打分、筛选或重试。
- 文件选择与波形区保持 6:4，左右工作区、可收起侧栏、自动刷新进度。
- 上传音频自动显示波形，一键裁剪、精确选区、预听、恢复原始上传。
- 独立的人声分离入口：环境降噪、音乐分离、组合处理、人声和背景音分别试听、导出。
- 启动时预加载模型，之后常驻；取消时保留已经完成的结果。

运行不需要外部网络；模型和依赖均已包含。首次打开仍需把模型从磁盘加载到显卡，关机或退出软件后下次需重新加载。不同随机种子不保证每份听感必然明显不同；识别文字也需要人工判断。

## 数据与许可

安装包不含原开发电脑的上传录音、生成音频、任务记录、日志、GitHub 凭据或下载缓存。使用后音频与记录保存在安装目录 `data/`，日志位于 `logs/`。软件需要对安装目录有写入权限，默认安装到当前用户目录。

程序、模型和第三方运行库各自适用原始许可。IndexTTS 原始完整许可位于 `engines/index/LICENSE`、`LICENSE_ZH.txt` 和 `engines/index/checkpoints/LICENSE`；其他许可见 `THIRD_PARTY_NOTICES.md` 及所附运行库和模型目录。安装前请阅读并接受这些许可。

若缺少分卷或校验失败，请从可信私有发布重新获取该分卷；安装器不会自动联网下载。若显卡检查失败，请查看安装日志并核对显卡及驱动；已解压的程序文件会保留，修复驱动后重新运行安装器即可继续检查。
